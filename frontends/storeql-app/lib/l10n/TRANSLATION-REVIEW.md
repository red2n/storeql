# Translations awaiting a native speaker

Each new string ships in all eight languages at once, so a sign-in page never mixes languages. When
no translator is at hand the non-English text is drafted, then listed here until a native speaker has
read it in context and either confirmed or corrected it. Once confirmed, remove its row. Correct a
string in its `app_<locale>.arb` file and regenerate (`flutter gen-l10n`).

When reviewing, read the string on its screen as well as in the file: Urdu and Arabic run right to
left, and a label that fits in English may wrap or clip in Bengali or Gujarati.
